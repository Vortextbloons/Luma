Fullscreen cursor freeze test move the pointer over the grid, then click

Watch the drawn pointer while this page is fullscreen. If the pointer image freezes in one spot but the highlighted cell and the counter keep following your real mouse, the page is fine and Windows is failing to move the hardware cursor plane. Exit and re-enter fullscreen to recover. This is the DWM/MPO compositor bug seen with some AMD graphics drivers; it also happens in Edge, VS Code, and other Chromium apps.
